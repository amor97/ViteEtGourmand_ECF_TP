# ViteEtGourmand_ECF_TP# Vite & Gourmand - Application Traiteur

Application web développée dans le cadre de l'ECF "Développeur Web et Web Mobile".  
Ce projet permet la gestion des commandes de menus traiteur pour l'entreprise "Vite & Gourmand".

## 🚀 Installation et Démarrage

Pour faire fonctionner ce projet en local sur votre machine :

1. **Cloner le dépôt** (ou télécharger les fichiers)
2. **Installer les dépendances** :
   ```bash
   npm install
   ```
3. **Lancer le serveur de développement** :
   ```bash
   npm run dev
   ```
4. **Ouvrir l'application** via le lien affiché dans le terminal (ex: `http://localhost:5173`).

## 🛠 Stack Technique

- **Frontend** : React, TypeScript, Vite
- **Style** : Tailwind CSS (via CDN pour cet exercice)
- **Routing** : React Router Dom
- **Graphiques** : Recharts

## 📋 Fonctionnalités

- Catalogue des menus avec filtres (Prix, Thème, Régime)
- Détail des menus et gestion des stocks
- Prise de commande avec calcul automatique (Frais de port + Remise quantité)
- Back-office Administrateur (Suivi des statuts, Dashboard CA)
- Gestion des avis clients
